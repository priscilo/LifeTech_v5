# Security Policy - LifeTech v5 🔐

## Supported Versions
Actualmente mantenemos activamente la rama `main`.
Se recomienda a todos los colaboradores y usuarios trabajar siempre sobre la última versión estable.

---

## Reporting a Vulnerability
Si encuentras una vulnerabilidad en LifeTech v5:

1. **No abras un Issue público.**
2. Envía un reporte privado a nuestro equipo de seguridad:
   - Email: seguridad@lifetech.com (ejemplo, reemplazar por el real)
3. Incluye en tu reporte:
   - Descripción clara del problema.
   - Pasos para reproducirlo.
   - Impacto potencial.
   - Sugerencias de mitigación (si las tienes).

Nos comprometemos a responder en un plazo máximo de **72 horas** y a trabajar en una solución lo antes posible.

---

## Best Practices for Contributors
- Nunca subas credenciales ni claves API al repositorio.
- Usa archivos `.env` para variables sensibles (no versionados).
- Revisa que tu código cumpla con las guías de seguridad antes de abrir un Pull Request.
- Reporta cualquier comportamiento sospechoso en dependencias externas.

---

## Security Updates
- Las dependencias se auditan regularmente con herramientas como `npm audit` y `pnpm audit`.
- Se aplican parches de seguridad de manera prioritaria.
- Los cambios críticos se comunican en el `CHANGELOG.md`.
