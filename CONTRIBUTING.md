# Contributing to LifeTech v5

Gracias por tu interés en contribuir a LifeTech v5 🚀

## Cómo contribuir
1. Haz un fork del repositorio.
2. Crea una rama descriptiva:
   ```bash
   git checkout -b feat/nueva-funcionalidad
   ```
3. Haz tus cambios y commits siguiendo la convención:
   - `feat:` nueva funcionalidad
   - `fix:` corrección de bug
   - `docs:` documentación
   - `chore:` tareas menores
4. Haz push a tu rama:
   ```bash
   git push origin feat/nueva-funcionalidad
   ```
5. Abre un Pull Request.

## Buenas prácticas
- Mantén el código limpio y modular.
- Añade pruebas si es posible.
- Actualiza la documentación relacionada.
```

# Política de Seguridad

## Reporte de vulnerabilidades
Si encuentras una vulnerabilidad en LifeTech v5:

1. **No abras un Issue público.**
2. Envía un correo a: seguridad@lifetech.com (ejemplo).
3. Describe el problema y pasos para reproducirlo.

Nos comprometemos a responder en un plazo máximo de 72 horas.
```
